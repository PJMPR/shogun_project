# pj-studies-faculty

Mockup mikrofrontendu „Kadra”, dostępny w hoście pod `/faculty` i wystawiony przez Native Federation jako `mfe-faculty`.

Uruchomienie lokalne:

```powershell
npm ci
npm start
```

Mikrofrontend działa na porcie `4208`. Dane są przykładowe i są przechowywane wyłącznie w pamięci przeglądarki. Backend kadry, trwały zapis stopni i tytułów oraz eksport XLSX pozostają poza zakresem tego etapu.
